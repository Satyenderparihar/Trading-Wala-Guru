# 🏦 STOCK EXCHANGE क्या होता है?

## 📌 Definition (Simple)

👉 **Stock Exchange = एक marketplace जहाँ shares खरीदे और बेचे जाते हैं**

मतलब:
जहाँ लोग company के shares trade करते हैं

---

# 🧠 Kahani (Real Life Example)

मान ले एक बड़ा सब्ज़ी मंडी है 🥦

* लोग आते हैं → खरीदते हैं
* लोग आते हैं → बेचते हैं

👉 यही काम stock exchange करता है
बस यहाँ सब्ज़ी नहीं, **company के shares** बिकते हैं 💰

# 📊 Stock Exchange कैसे काम करता है?

## 🔄 Flow (Step-by-Step)

1️⃣ Buyer order डालता है
2️⃣ Seller order डालता है
3️⃣ Exchange match करता है
4️⃣ Trade complete ✅

---

# 📉 Smart Flow Diagram

```
👤 Buyer → (Buy Order)
             ↓
        🏦 Stock Exchange
             ↑
👤 Seller ← (Sell Order)

👉 Match = Trade Done 💹
```
