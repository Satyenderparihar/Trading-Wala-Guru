# 📘 PIPs Kya Hote Hain aur Kaise Kaam Karte Hain?

---

# 1. Pip क्या होता है

Pip = Price movement को measure करने की unit।

```
Pip = Market movement की counting unit
```

Jab price thoda move karta hai, us movement ko **pip mein measure kiya jata hai**.

---

# 2. Forex Pair Mein Pip

Most forex pairs mein:

```
1 Pip = 0.0001
```

Example — EURUSD:

```
1.1000 → 1.1001
```

Difference:

```
0.0001 = 1 Pip
```

---

# 3. Forex Example

Trade:

```
Entry = 1.1000
Exit  = 1.1005
```

Difference:

```
0.0005
```

Calculation:

```
0.0005 ÷ 0.0001 = 5 Pips
```

---

# 4. 100 Pip Example

Trade:

```
Entry = 1.1000
Exit  = 1.1100
```

Difference:

```
0.0100 ÷ 0.0001 = 100 Pips
```

---

# 5. XAUUSD (Gold) Mein Pip

Gold mein pip size alag hota hai:

```
1 Pip = 0.01
```

| Price Move | Pips |
|------------|------|
| 0.01 | 1 Pip |
| 0.10 | 10 Pips |
| 1.00 | 100 Pips |

```
Gold $1 move = 100 Pips
```

---

# 6. Gold Example

Trade:

```
Entry = 2000
Exit  = 2001
```

```
1 ÷ 0.01 = 100 Pips
```

---

# 7. Pip vs Points

```
Pip   = Standard unit (EURUSD mein 4th decimal)
Point = Pip ka 10th part (5th decimal = pipette)
```

Example:

```
EURUSD
1.10005 → 1.10006 = 1 Point (0.1 Pip)
1.10000 → 1.10010 = 1 Pip (10 Points)
```


| Lot | Profit |

---

# 10. Pip Formula

```
Pips = Price Difference ÷ Pip Size
```

Example:

```
EURUSD: 1.1000 → 1.1050
0.0050 ÷ 0.0001 = 50 Pips

Gold: 2000 → 2010
10 ÷ 0.01 = 1000 Pips
```

---

# 11. USDJPY Special Case

Japanese Yen ke pairs mein pip alag hota hai:

```
USDJPY mein:
1 Pip = 0.01 (2 decimal places)
```

Example:

```
145.00 → 145.01 = 1 Pip
145.00 → 146.00 = 100 Pips
```

---

# 13. Pip Ke Saath Risk Calculation

Agar tumhara account $1000 hai aur tum max 2% risk lena chahte ho:

```
Max Risk = $1000 × 2% = $20

0.01 lot pe 1 pip = $0.10
$20 ÷ $0.10 = 200 pips = max stop loss
```

Yeh formula use karo stop loss calculate karne ke liye.

---

# 14. Common Pip Mistakes

| Mistake | Problem |
|---------|---------|
| Gold pip confusion | Wrong profit calculation |

| No stop loss | Account blow |
| News time ignore | High volatility loss |

```
Pips control = Risk control

Pip clear hai toh:
→ Lot size sahi choose karoge
→ Profit expectation sahi hogi
→ Stop loss sahi set hoga
→ Risk manage hoga
```
