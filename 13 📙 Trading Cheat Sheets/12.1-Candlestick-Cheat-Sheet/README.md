# 12.1 - Candlestick Cheat Sheet (Quick Reference)

Trading mein candlesticks market ki psychology ko samajhne ka sabse fast tareeka hain. Niche kuch sabse important patterns aur unka matlab diya gaya h:

### 🟢 Bullish Patterns (Market Up Jane ka Signal)
| Pattern Name | Visual Description | Meaning / Action |
| :--- | :--- | :--- |
| **Hammer** | Choti body, lambi niche ki wick. | Niche se buying pressure h. Reversal signal. |
| **Inverted Hammer** | Choti body, lambi upar ki wick (niche trend mein). | Sellers thak chuke hain, buyers entry kar rahe hain. |
| **Bullish Engulfing** | Badi green candle pichli red candle ko poora cover karti h. | Strong buying momentum shuru ho gaya h. |
| **Morning Star** | Ek bari red, ek choti candle, aur fir bari green candle. | Downtrend khatam, uptrend ki shuruat. |

### 🔴 Bearish Patterns (Market Down Jane ka Signal)
| Pattern Name | Visual Description | Meaning / Action |
| :--- | :--- | :--- |
| **Shooting Star** | Choti body, lambi upar ki wick (uptrend mein). | Upar se rejection h. Reversal signal. |
| **Hanging Man** | Hammer jaisa dikhta h par uptrend ke top par. | Uptrend kamzor ho raha h, sambhal jao. |
| **Bearish Engulfing** | Badi red candle pichli green candle ko poora cover karti h. | Strong selling momentum shuru ho gaya h. |
| **Evening Star** | Ek bari green, ek choti candle, aur fir bari red candle. | Uptrend khatam, downtrend ki shuruat. |

### ⚪ Neutral / Indecision Patterns
| Pattern Name | Visual Description | Meaning / Action |
| :--- | :--- | :--- |
| **Doji** | Opening aur closing price lagbhag same. | Market confused h. Breakout ka wait karein. |
| **Spinning Top** | Choti body, dono taraf barabar wicks. | Bulls aur Bears dono barabar fight kar rahe hain. |

> [!TIP]
> **Pro Tip**: Candlestick patterns ko hamesha Support ya Resistance levels par hi trade karein. Beech market mein inka value kam hota h.
