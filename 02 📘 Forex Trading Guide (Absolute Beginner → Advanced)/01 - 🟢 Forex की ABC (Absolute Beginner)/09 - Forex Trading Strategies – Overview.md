# 1. Forex Trading Strategy क्या होती है

Forex Trading Strategy = Market में **entry, exit और risk control का plan**।

Simple rule

```
Strategy = कब buy करना + कब sell करना + कितना risk लेना
```

अगर strategy नहीं है तो trading बन जाती है

```
Guessing
```

और guessing से profit consistent नहीं होता।

---

# 2. Forex Trading Strategies का Purpose

Strategy trader को 4 चीजें clear करती है।

| Element   | Meaning                 |
| --------- | ----------------------- |
| Entry     | Trade कब लेना           |
| Stop Loss | Loss कहाँ रोकना         |
| Target    | Profit कहाँ लेना        |
| Risk      | कितना capital risk करना |

---

# 3. Most Popular Forex Trading Strategies

Forex market में कई strategies use होती हैं।

| Strategy         | Use                         |
| ---------------- | --------------------------- |
| Trend Following  | Trend के साथ trade          |
| Breakout Trading | Strong level break पर entry |
| Scalping         | Small moves से profit       |
| Range Trading    | Support-Resistance bounce   |
| News Trading     | Economic news पर trade      |

---

# 4. Trend Following Strategy

यह सबसे common strategy है।

Rule

```
Trend up → Buy
Trend down → Sell
```

Example

```
Gold uptrend
Higher highs
Higher lows
```

Entry

```
Pullback पर buy
```

---

# 5. Breakout Strategy

जब price strong level तोड़ता है।

Example

```
Resistance = 2000
```

अगर price

```
2000 break
```

करता है तो

```
Buy breakout
```

क्योंकि market momentum strong होता है।

---

# 6. Scalping Strategy

Scalping में traders छोटे moves से profit लेते हैं।

Typical target

```
5 – 15 pips
```

Example

```
XAUUSD
Entry = 2000
Exit = 2002
```

Move

```
$2
```

अगर lot

```
0.01
```

Profit

```
$2
```

# 7. Range Trading Strategy

# 10. Risk Management (Most Important)

Professional traders हमेशा risk control करते हैं।

Rule

```
Risk per trade = 1% – 2%
```

Example

```
Capital = ₹100000
Risk = ₹1000
```

Stop loss हमेशा use करना चाहिए।
