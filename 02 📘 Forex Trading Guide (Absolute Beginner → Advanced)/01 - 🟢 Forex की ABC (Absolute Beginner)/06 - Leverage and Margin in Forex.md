# 1. Leverage क्या होता है

Leverage = Broker का दिया हुआ **borrowing power**।

मतलब

```id="7q9v2d"
छोटे पैसे से बड़ी trade लेना
```

Example

अगर आपके पास

```
$100
```

और leverage

```
1:100
```

तो आप

```
$10,000
```

की trade control कर सकते हो।

---

# 2. Leverage Ratio

Leverage हमेशा ratio में लिखा जाता है।

| Leverage | Meaning           |
| -------- | ----------------- |
| 1:10     | 10x buying power  |
| 1:50     | 50x buying power  |
| 1:100    | 100x buying power |
| 1:500    | 500x buying power |

Example

```id="2w6ty8"
Leverage 1:100
```

मतलब

```id="p8h1xg"
$1 = $100 trade power
```

---

# 3. Margin क्या होता है

Margin = Trade खोलने के लिए account में block होने वाला पैसा।

Simple rule

```id="0fsvxq"
Margin = Trade open करने के लिए required balance
```

---

# 4. Leverage vs Margin Relation

दोनों एक दूसरे से जुड़े होते हैं।

Formula

```id="cln0p5"
Margin = Trade Size ÷ Leverage
```

# 9. High Leverage Risk

High leverage dangerous भी हो सकता है।

Example

```
Leverage = 1:500
Lot = 5
```

अगर market

```
$1
```

move करे

तो huge loss हो सकता है।

# 10. Professional Traders Rule

Professional traders

```
Low lot size
Controlled leverage
Strict stop loss
```

follow करते हैं।

# 12. Biggest Mistakes

| Mistake            | Result       |
| ------------------ | ------------ |
| Very high leverage | Account blow |
| Big lot trading    | Huge loss    |
| No stop loss       | Margin call  |
