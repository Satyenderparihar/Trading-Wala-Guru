# 1. Lot Size क्या होता है

Lot Size = Trading में **position का size**।

मतलब

```
आप market में कितनी quantity trade कर रहे हो
```

Simple rule

```
Lot Size = Trade की quantity
```

---

# 2. Real Life Example

मान लो आप **सोना खरीदते हो**।

| Quantity  | Example      |
| --------- | ------------ |
| 1 ग्राम   | छोटा trade   |
| 10 ग्राम  | medium trade |
| 100 ग्राम | बड़ा trade   |

Forex में भी ऐसा ही होता है।

| Trade Size | Lot  |
| ---------- | ---- |
| Small      | 0.01 |
| Medium     | 0.10 |
| Large      | 1.00 |

---

# 3. Forex Lot Types

Forex में 3 main lot होते हैं।

| Lot Type     | Lot Size | Units  |
| ------------ | -------- | ------ |
| Standard Lot | 1.00     | 100000 |
| Mini Lot     | 0.10     | 10000  |
| Micro Lot    | 0.01     | 1000   |

# 4. Pip Value vs Lot Size

Lot size बढ़ने से profit भी बढ़ता है।

### Forex pairs

| Lot      | 1 Pip Value |
| -------- | ----------- |
| 1 Lot    | $10         |
| 0.10 Lot | $1          |
| 0.01 Lot | $0.10       |

Example

```
10 pips move
```

| Lot   | Profit |
| ----- | ------ |
| 1 Lot | $100   |
| 0.10  | $10    |
| 0.01  | $1     |

# 8. Lot Size क्यों important है

Lot size गलत हुआ तो

```
छोटा move भी बड़ा loss दे सकता है
```

Example

Account

```
$100
```

अगर

```
5 lot trade
```

ले लिया

तो market move

```
$1
```

ही account destroy कर सकता है।

---

# 9. Lot Size Calculation Rule

Professional traders rule

```
Lot Size = Risk ÷ Stop Loss
```

Example

Capital

```
₹1,00,000
```

Risk

```
1%
= ₹1000
```

Stop loss

```
$2
```

Lot size

```
0.50 lot
```
